# Responsible AI Disclosure
The author of this repository would like to declare that LLMs were used during the revision process of the firmware, software, and electronics. It is not expected for LLM generated outputs to cause issues through responsible use practices.

## Firmware
LLM agents were used to perform basic revisions such as pin mappings, renaming of functions, and boiler plate code. All code generated during the revision process has beed reviewed line-by-line for possible bugs and coding atrocities. Additionally, the author worked with the LLM on a step-by-step basis to ensure that the agent remained in alignment with the project goals.

## Software
The user interface (UI) of the progressive web app (PWA) was revised using LLMs to streamline user experience. Additionally, in-browser storage using DBOPFS was also revised using LLMs due to skill issues in javascript and html/css.

## Electronics
LLM agents were used during the review phase where each component spawned an independent agent whom utilized datasheets to validate schematics and component placement on the PCB. This process effectively allowed for a second pair of eyes to point out potential issues during the design of the electronics.

## LLM-assisted contributions
LLM generated artifacts are generally accepted as long as they have been *THOROUGHLY* reviewed. Sometimes, this may take longer than writing code by hand. It is important to understand anything and everything a LLM generates in order to avoid future issues. Those who do not take the time to review their own code will not be given time for proper review or contributions.
