User Manual
===========

The manual will be a concise instrument reference, similar in scope to the
manuals supplied with commercial digital delay and pulse generators. It will
cover system and channel parameters, their meanings and limits, timing modes,
triggering, gating, and everyday device operation.

It will be authored in LaTeX and distributed as a printable PDF. This page is
reserved for that document; the manual is separate from the detailed
:doc:`User Guide <../users_guide/index>`, :doc:`API Reference
<../api_reference/index>`, and experimental case studies.
