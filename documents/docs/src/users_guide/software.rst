Software Guide
==============

Overview
--------

OpenSync can be controlled with its Python package or its installable browser
application (PWA). Both communicate with the device through its USB serial
SCPI interface. Use Python for scripts and notebooks, or the PWA to edit
settings and send commands from a graphical interface.

Installation
------------

Install the Python package from a wheel in an OpenSync release archive, or run
the PWA from its Node.js server and install it through your browser.
